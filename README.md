# ZomBox

ZomBox — экспериментальный прототип VR-игры, разработанный на Unity с использованием C#.  
Проект ориентирован на проработанные механики взаимодействия в виртуальной реальности и исследование возможностей VR-геймплея.

## Ключевые особенности

- **VR-игровой процесс** с акцентом на физическое взаимодействие
- **Проработанная механика ближнего боя**:
  - реализована катана с учётом физики движения
  - удары засчитываются только при полноценном замахе, а не при простом касании
- Работа с игровыми объектами, сценами и состояниями в Unity
- Эксперименты с архитектурой игрового приложения

## AI противников (эксперимент)

В рамках проекта предпринимались попытки разработки AI для атакующих ботов.  
Планировалось обучение моделей поведения противников, однако из-за ограниченных вычислительных ресурсов и сложности обучения идея была отложена на этапе подготовки и обучения AI.

## Цели проекта

- Практика разработки VR-приложений на Unity
- Изучение игровых механик и физики взаимодействия
- Понимание архитектуры интерактивных приложений
- Эксперименты с AI в игровом контексте

## Стек технологий

- Unity
- C#
- VR SDK (в зависимости от сборки)
- Git

Активная разработка приостановлена, но код сохранён как результат учебной и исследовательской работы.
